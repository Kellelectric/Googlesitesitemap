# Local SEO: NAP Consistency & Citation Plan

Prepared as a reference doc for launch. This is off-site work — no code
changes required, just consistent, manual submissions. Hand this to
whoever manages Google Business Profile / directory listings.

## The exact NAP block to use everywhere

Search engines match business listings across the web by comparing
**Name, Address, Phone** character-for-character. Inconsistent formatting
(a different suite number, "St." vs "Street", a different phone format)
weakens local ranking signals. Use this exact block on every submission
below — copy/paste, don't retype:

```
Business Name: Kell Electricals Ltd
Address:       741 Alexandria Crescent, Wuse 2, Abuja, FCT, Nigeria
Phone:         +234 814 020 5895
Website:       https://kellelectricals.com
Email:         info@kellelectricals.com
Category:      Electrical Contractor / Electrician
Hours:         Mon–Fri 8:00 AM–5:00 PM, Sat 10:00 AM–3:00 PM, Sun Closed
```

Whatever is already live on the Google Business Profile listing should be
the master source of truth — if it differs from the above in any way,
update this doc (and the Business Profile) rather than leaving two
different versions live.

## Priority 1: Regulatory directories (industry credibility + real backlink)

- **NEMSA Directory of Corporate Electrical Contractors** —
  https://nemsa.gov.ng/directory-of-corporate-electrical-contractors/
  NEMSA maintains a real, public directory of certified electrical
  contractors. Confirm Kell Electricals is listed here (or apply to be
  added, per NEMSA's own process) — since the site already claims NEMSA
  certification, being findable in NEMSA's own directory is both a
  credibility check and a genuine authoritative backlink.
- **COREN verification portal** — https://portal.coren.gov.ng/verification
  This is a registration-status lookup, not a public business directory,
  so it won't generate a listing/backlink — but worth confirming the
  firm's/engineer's COREN registration resolves correctly here, since the
  site publicly claims COREN certification.

## Priority 2: General Nigerian business directories

- **ConnectNigeria** — https://www.connectnigeria.com/businesses
  Listing guide: https://articles.connectnigeria.com/how-to-list-your-business-on-connect-nigeria-in-10-steps/
  One of the larger, more established Nigerian directories.
- **Abuja Galleria** — https://www.abujagalleria.com/submission/
  Abuja-specific — high relevance since the business is Abuja-based.
- **Nigeria Galleria** — http://www.nigeriagalleria.com/
  Established general directory; look for "Add Listing" / "Register
  Business" on the site (no single stable submission URL confirmed).
- **VConnect** — https://www.vconnect.com
  Large Nigerian local-search directory; look for "List Your Business"
  on the site (no single stable submission URL confirmed).

## Priority 3: General/global directories worth a listing

- **Google Business Profile** — already live (this is the source of the
  4.8★ / 192 reviews used sitewide). Keep it as the canonical NAP source.
- **Bing Places for Business** — free, and Bing Webmaster Tools should be
  set up alongside Google Search Console once the domain is live (see
  "Still needed" below).
- **Trustpilot** — already linked in the footer/socials.

## Still needed once the domain is live (not directory-related)

- Verify `kellelectricals.com` in **Google Search Console**, submit
  `sitemap.xml`.
- Verify in **Bing Webmaster Tools** too (smaller volume, but zero-cost
  to set up once GSC is done).
- Confirm the Google Business Profile's address/phone/hours match the
  NAP block above exactly.

## What isn't on this list, deliberately

- No link-farm / low-quality "SEO backlink package" directories. Volume
  of low-quality citations does not help and can attract a Google
  manual-action risk; the directories above were chosen for being
  real, Nigeria-relevant, and either regulatory or high-traffic.
- No submission was made on Kell Electricals' behalf — every URL above
  needs a human to actually create the account/listing and verify the
  business (phone/email/postcard verification is normal for these).
